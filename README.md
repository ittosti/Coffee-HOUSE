# ☕ طلبات المقهى | Commandes du Café

تطبيق ويب لتسجيل طلبات السلع الخاصة بالمقهى (قهوة، سكر، مشروبات غازية...) وإرسالها عبر واتساب.

## 🚀 التشغيل على GitHub Pages

1. ارفع الملف `index.html` إلى مستودع GitHub
2. من **Settings → Pages** اختر الفرع `main` والمجلد `/ (root)`
3. ستحصل على رابط مثل: `https://username.github.io/repo-name`
4. أرسل الرابط لعمالك — يعمل مباشرة على الهاتف دون تثبيت

## ✨ المميزات

- 📂 فئات جاهزة + إمكانية إضافة فئات ومنتجات جديدة
- ✏️ تعديل أسماء الفئات والمنتجات وأيقوناتها
- 🖼️ إضافة صور للفئات والمنتجات وتغييرها لاحقاً (تُحفظ محلياً على الجهاز)
- 🗑️ حذف أي فئة أو منتج
- 🔐 **كل عمليات الإدارة (إضافة/تعديل/حذف) محمية برمز سري**
- ➕/➖ تحديد الكميات بضغطة واحدة
- 📲 إرسال الطلب إلى **مجموعة واتساب** (نسخ تلقائي + فتح المجموعة) أو إلى **رقم مباشر**
- ⭐ "الأكثر طلباً" حسب استخدام كل جهاز
- 💾 تصدير/استيراد البيانات بصيغة JSON
- 🔍 بحث فوري + ملاحظات إضافية
- 🌙 تصميم داكن مخصص للهواتف ويعمل دون اتصال بعد أول تحميل

## 🔐 الرمز السري

عمليات إضافة/تعديل/حذف الفئات والمنتجات تتطلب إدخال الرمز السري في صفحة الإعدادات ⚙️.
🔒 اضغط زر "قفل" لإغلاق منطقة الإدارة (أو أعد تحميل الصفحة).

## ⚙️ ملاحظة حول إرسال المجموعة

واتساب لا يسمح بتعبئة رسالة مسبقة داخل مجموعة عبر رابط. لذلك عند الضغط على "إرسال للمجموعة":
1. تُفتح **مجموعة الواتساب** مباشرة من نقرة الإرسال.
2. يتم نسخ الطلب تلقائياً إن سمح المتصفح بذلك.
3. يلصق العامل الرسالة داخل المجموعة ويضغط إرسال ✅

مهم: واتساب لا يسمح للتطبيق بإرسال رسالة تلقائياً إلى مجموعة أو تعبئة نصها مسبقاً عبر رابط المجموعة؛ يلزم اللصق والضغط على إرسال يدوياً.
